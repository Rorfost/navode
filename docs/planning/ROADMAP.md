# Roadmap

Roadmap items are directional, not delivery commitments.

## Phase 0 — Repository foundation

Monorepo, documentation, CI, linting, testing, base UI, web shell, MV3 extension skeleton, and API health skeleton.

## Phase 1 — Useful new tab

New-tab override, command bar, quick links, local settings, keyboard shortcuts, scratchpad, focus timer, and basic project launcher.

## Phase 2 — Power-user features

Custom aliases, workspace capsules, snippets, session groups, import/export, smart launcher, and developer utilities.

## Phase 3 — Integrations

GitHub, Codeforces, calendar, service health, and optional API-backed helpers.

## Phase 4 — Sync

Optional account, carefully designed sync, cross-device settings, and migrations.

## Phase 5 — Public product readiness

Onboarding, Chrome Web Store preparation, privacy policy, public site, explicit telemetry decision, accessibility polish, and release process.
