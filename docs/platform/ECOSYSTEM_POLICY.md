# Navode Ecosystem Policy

We welcome community contributions and plugins to the Navode ecosystem. To maintain a high-quality experience, all official and community plugins must adhere to the following policies.

## 1. Transparency

Plugins must clearly describe their functionality in their manifest. Misleading descriptions are not allowed.

## 2. Minimal Permissions

Plugins should only request the capabilities they strictly need to function.

## 3. Performance

Plugins must not degrade the performance of the Navode Shell. Overuse of capabilities that lead to slow rendering will result in a plugin being marked as "unverified".

## 4. Privacy First

Plugins must respect user data. Any plugin found to be improperly accessing or transmitting user data without explicit consent will be immediately banned from the registry.

## Plugin Statuses

- **Official**: Maintained by the Navode core team.
- **Community**: Built by the community and available for installation.
- **Unverified**: Not yet reviewed, use at your own risk.
