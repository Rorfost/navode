# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |

## Reporting a vulnerability

Please do not report exploitable vulnerabilities in public GitHub issues, discussions, pull requests, or social media.

Navode does not publish a security email address, and GitHub Private Vulnerability Reporting has not been confirmed as enabled for this repository. The repository owner must enable it before a public private-reporting channel can be advertised. Until then, do not disclose exploit details publicly.

When a private reporting channel is available, include:

- a clear description and affected Navode version or commit;
- reproduction steps or a minimal proof of concept;
- impact assessment and affected component;
- any suggested mitigation; and
- contact details only if you want a response.

Reports should avoid including exported Navode data, credentials, tokens, private URLs, or other unnecessary personal data.

## Response expectations

The repository owner will review confirmed reports, assess impact, coordinate a fix when appropriate, and credit reporters only with their permission. Do not publish details until a fix or coordinated disclosure plan is available.
